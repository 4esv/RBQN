# RBQN Roadmap

## Milestone 1: Core Language Completeness
**Goal:** RBQN can compile and execute arbitrary BQN programs, passing the official test suite.

---

### Phase 1: Fix Bootstrap Pipeline
**Goal:** Runtime0 → Runtime1 → Compiler → Formatter all execute correctly.

**Why first:** Everything downstream depends on a working compiler. Runtime0 has 2 failing tests (+´ returns wrong result, +¨ type error) that cascade into runtime1 failures.

**Requirements:** R-BOOT-2, R-BOOT-3, R-BOOT-4, R-BOOT-5, R-BOOT-6, R-BOOT-7

**Key tasks:**
1. Debug and fix +´ (fold) — likely accumulator or operand dispatch issue
2. Debug and fix +¨ (each) — type error in array element dispatch
3. Verify runtime0 produces correct ~24 core functions
4. Execute runtime1 end-to-end, verify 64-value runtime output
5. Implement SetPrims callback (Decompose + PrimInd)
6. Implement SetInv callback (inverse tables)
7. Load compiler, verify it can compile simple BQN expressions
8. Load formatter, verify •Fmt and •Repr work

**Success criteria:** `CBQN_PATH=/path/to/CBQN cargo run -- -e '1+1'` outputs `2`

**Plans:** 3 plans

Plans:
- [x] 01-01-PLAN.md — Fix fork/each bugs and verify runtime0 correctness
- [ ] 01-02-PLAN.md — Wire setPrims/setInv, runtime1, and compiler end-to-end
- [x] 01-03-PLAN.md — Load formatter and verify •Fmt/•Repr output (2/2 tasks, formatter falls back gracefully)

### Phase 2: Language Completeness & Test Suite
**Goal:** Missing modifiers, essential system functions, primitive edge cases — then pass all 13 official BQN test files.

**Why second:** With a working compiler from Phase 1, this phase fills the remaining language gaps and proves correctness against the official test suite. Most primitives (43/44) and modifiers (16/20) are already done — this closes the gaps.

**Requirements:** R-MOD-3, R-MOD-4, R-MOD-5, R-MOD-6, R-PRIM-5, R-PRIM-6, R-PRIM-7, R-SYS-1, R-SYS-2, R-SYS-3, R-SYS-4, R-SYS-5, R-SYS-6, R-SYS-7, R-TEST-1, R-TEST-2, R-TEST-3, R-TEST-4, R-TEST-5, R-TEST-6, R-TEST-7, R-TEST-8, R-TEST-9, R-TEST-10, R-TEST-11, R-TEST-12, R-TEST-13

**Key tasks:**
1. Implement 4 missing modifiers: Undo (⁼), Under (⌾), Rank (⎉), Depth (⚇)
2. Implement essential system functions: •BQN/•ReBQN, •Show/•Out, •Import, •FChars/•FLines/•FBytes, •file namespace, •args/•path/•name/•wdpath/•state
3. Pervasive extension (deep array arithmetic), fill element propagation, identity elements for fold
4. Set up test runner against official BQN test suite (mlochbaum/BQN test/cases/*.bqn)
5. Fix failures across all 13 test files iteratively
6. Create CI pipeline to run test suite on every commit

**Success criteria:** All 13 official BQN test files pass with zero failures

---

### Phase 3: Self-Hosting & Independence
**Goal:** RBQN compiles itself without CBQN dependency — standalone binary.

**Why third:** Once the test suite passes, we have confidence to remove the CBQN bootstrap dependency. Also handles remaining system functions needed for real-world use.

**Requirements:** R-SELF-1, R-SELF-2, R-SELF-3, R-BOOT-8, R-SYS-8, R-SYS-9, R-SYS-10, R-SYS-12, R-SYS-13, R-SYS-19, R-SYS-20

**Key tasks:**
1. Compile BQN compiler source (c.bqn) using RBQN's loaded compiler
2. Verify output bytecode matches CBQN-generated bytecode
3. Embed compiled bytecode in binary (checked into repo)
4. Remove CBQN_PATH build-time requirement
5. Verify bootstrap chain works with embedded bytecode
6. Implement remaining high-value system functions: •math, •UnixTime/•MonoTime/•Delay, •MakeRand/•rand, •platform, •SH, •Exit/•ParseFloat/•Hash/•Cmp, •FromUTF8/•ToUTF8
7. REPL mode with variable persistence

**Success criteria:** `cargo build && ./target/release/rbqn -e '1+1'` outputs `2` with no CBQN dependency

---

## Future Work (not phased)

These are valuable but not on the critical path to a working self-hosted BQN:

- **GPU acceleration:** Complete compute kernels (R-GPU-4 through R-GPU-11), VM integration, benchmarking — infrastructure already exists
- **CPU performance:** SIMD primitives, type-specialized dispatch, array squeeze
- **Advanced system functions:** •FFI, •HashMap, •bit, •term, •_while_, •ns (R-SYS-11, R-SYS-14 through R-SYS-18)

---

## Phase Dependency Graph

```
Phase 1 (Bootstrap) ──→ Phase 2 (Language + Tests) ──→ Phase 3 (Self-Hosting)
```

- Phase 1 is planned (3 plans, verified)
- Phase 2 is the bulk of remaining language work but most foundations already exist
- Phase 3 is the finish line — standalone RBQN binary
- GPU and performance work deferred to future milestones (infrastructure already in place)
