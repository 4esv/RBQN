Fix Bug 2 — Each modifier returns Boxed arrays in `crates/rbqn-vm/src/modifiers.rs`:

Add a `results_to_arr` helper function that converts `Vec<B>` results to a typed array when all elements are numeric scalars, otherwise keeps as Boxed:

```rust
fn results_to_arr(results: Vec<B>, shape: Vec<usize>) -> B {
    if !results.is_empty() && results.iter().all(|b| b.is_f64()) {
        let vals: Vec<f64> = results.iter().map(|b| b.o2f()).collect();
        let mut out = rbqn_core::BqnArr::new_vec_f64(vals);
        out.shape = shape;
        return crate::vm::tag_arr(rbqn_core::array::squeeze_num(out));
    }
    let mut out = rbqn_core::BqnArr::new_vec_b(results);
    out.shape = shape;
    crate::vm::tag_arr(out)
}
```

Apply this helper in all modifier output sites: `each_c1`, `each_c2`, `cells_c1`, `cells_c2`, and any `scan_c1`/`scan_c2` that produce `new_vec_b` results. Replace `BqnArr::new_vec_b(results)` + `tag_arr` patterns with `results_to_arr(results, shape)`.

Also check for character results: extend the helper to detect when all results are characters (using `b.is_c32()` or similar) and produce a character array. If mixed types, keep Boxed.
