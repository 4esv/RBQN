**Problem:** `exec_string()` calls the BQN compiler and then EXECUTES the result. For self-compilation we need the raw compiler output (bc, objs, blocks, bodies) without executing it — so we can serialize it to .bin format.

**1. Add `compile_string()` to exec.rs:**

Create a new public function `compile_string(rt, code) -> Result<CompilerOutput>` that does exactly what `exec_string_inner` does up to and including line 86 (the `c2(rt.compiler, comp_args, src_b)` call), but instead of calling `compile_all` + `eval_fun_block`, it extracts the raw compiler output arrays and returns them as a struct.

```rust
pub struct CompilerOutput {
    pub bc: Vec<i32>,
    pub objs: Vec<B>,      // raw BQN values from compiler
    pub blocks: Vec<B>,    // raw BQN arrays from compiler
    pub bodies: Vec<B>,    // raw BQN arrays from compiler
}
```

The function:
- Builds compiler arguments the same way as exec_string_inner (rt_arr, sys_fn, empty var_names, empty var_depths)
- Calls `c2(rt.compiler, comp_args, src_b)` to invoke the compiler
- Extracts bc as Vec<i32> from comp_arr.get(0) (same as exec_string lines 91-101)
- Extracts objs, blocks, bodies as Vec<B> (same as exec_string lines 103-119)
- Returns CompilerOutput without executing anything
- Wraps in catch_unwind the same way exec_string does

**2. Add `encode_owned_bytecode()` to embedded/mod.rs:**

Create a public function `encode_owned_bytecode(obc: &OwnedBytecode, source_tag: &str) -> Vec<u8>` that serializes an OwnedBytecode to the RBQN wire format. This is the reverse of `decode_bytecode()`.

The encoding follows the same wire format as rbqn_gen's `encode_bytecode()` but works from OwnedBytecode (which has typed ObjectEntry/BlockEntry) instead of ParsedComponent. The format:

```
[magic: b"RBQN"] [version: 1u32 LE]
[tag_len: u16 LE] [tag: bytes]
[bc_len: u32] [bc: i32 x bc_len]
[iarrs_count: u32] for each: [len: u32] [data: i32 x len]
[objs_count: u32] for each: [tag: u8] [payload]
[blocks_count: u32] for each: [tag: u8] [payload]
[bodies_count: u32] [data: u32 x count]
```

For ObjectEntry encoding:
- Provide(n) -> tag 0, u32 LE
- Runtime(n) -> tag 1, u32 LE
- RuntimePrev(n) -> tag 2, u32 LE
- Float(v) -> tag 3, f64 LE
- Char(c) -> tag 4, u32 LE
- Str(chars) -> tag 5, u32 len + u32 x len
- IArr(n) -> tag 6, u32 LE

For BlockEntry encoding:
- IArr(n) -> tag 0, u32 LE
- Info { typ, iarrs0_idx, data_idx } -> tag 1, u8 typ + u32 iarrs0_idx + u32 data_idx

For bodies: u32 per entry.

**3. Add `compiler_output_to_owned()` helper to exec.rs:**

Create a function that converts a `CompilerOutput` (containing raw BQN B values) into an `OwnedBytecode` (containing typed ObjectEntry/BlockEntry). This is the key conversion:

The compiler returns `objs` as BQN values. Each object is one of:
- A float scalar -> ObjectEntry::Float(v)
- A char scalar -> ObjectEntry::Char(c)
- A string (char array) -> ObjectEntry::Str(chars)
- An integer array -> needs to be stored as iarrs entry + ObjectEntry::IArr(idx)
- A function (provide/runtime ref) -> This is the hard case

For functions: the compiler's object array contains references to `provide[n]` or `runtime[n]`. We need to identify WHICH provide/runtime index a function value corresponds to. Approach:
- Accept `&[B]` provide and `Option<&[B]>` runtime_prev / runtime arrays as parameters
- For each object B value, check: is it a float? char? array? function?
- For functions, scan the provide array and runtime arrays to find which index matches (B values have unique bit patterns)
- If found in provide -> ObjectEntry::Provide(n)
- If found in runtime_prev -> ObjectEntry::RuntimePrev(n)
- If found in runtime -> ObjectEntry::Runtime(n)
- If not found -> This shouldn't happen for well-formed compiler output; log a warning and encode as Float(0.0)

For blocks: each block B is an array `[type, imm, bodyArg]`. If bodyArg is a scalar, it's a simple block -> BlockEntry::IArr(iarrs_idx). If bodyArg is a pair `[monadics, dyadics]`, it's a compound block -> BlockEntry::Info.

For bodies: each body B is an integer array `[bcOffset, varCount, ...]` -> store in iarrs and record iarrs index.

The function accumulates iarrs as it encounters integer arrays, building up the iarrs Vec and referring to them by index.

Important: bc itself also needs to go into iarrs (typically as iarrs[0] or at bc_idx position). Store bc in iarrs first, record bc_idx.

Signature:
```rust
pub fn compiler_output_to_owned(
    output: &CompilerOutput,
    provide: &[B],
    runtime_prev: Option<&[B]>,
    runtime: Option<&[B]>,
) -> OwnedBytecode
```

This function is complex but the logic mirrors the reverse of build_objs/build_blocks/build_bodies in bootstrap.rs.
