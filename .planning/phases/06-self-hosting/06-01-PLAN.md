Create the binary wire format and all supporting infrastructure:

**1. Binary format (in rbqn_gen.rs):**
Use a simple tag-length-value format. Little-endian throughout:
```
[magic: 4 bytes = b"RBQN"]
[version: u32 LE = 1]
[source_tag_len: u16 LE] [source_tag: bytes]
[bc_len: u32] [bc: i32×bc_len]
[iarrs_count: u32] for each: [len: u32] [data: i32×len]
[objs_count: u32] for each: [tag: u8] [payload per tag]
  tag 0=Provide(u32), 1=Runtime(u32), 2=RuntimePrev(u32), 3=Float(f64 LE), 4=Char(u32), 5=Str(u32 len + u32×len codepoints), 6=IArr(u32)
[blocks_count: u32] for each: [tag: u8]
  tag 0=IArr(u32), 1=Info(u8 typ + u32 iarrs0_idx + u32 data_idx)
[bodies_count: u32] [data: u32×bodies_count]
```

**2. rbqn-gen binary (`crates/rbqn/src/bin/rbqn_gen.rs`):**
Move the ENTIRE C-source parser from the current build.rs into rbqn_gen.rs — the `parse_cbqn_gen`, `parse_objects`, `parse_blocks`, `parse_bodies`, `parse_c32_char`, `parse_string_literal`, `parse_blockinfo`, `find_matching_paren`, `find_first_iarrs_ref`, `parse_array_size`, `c_float_to_rust` functions, plus the `ObjEntry`, `BlkEntry`, `ParsedComponent` types. Do NOT rewrite them — move as-is.

Add an `encode_bytecode(parsed: &ParsedComponent, source_tag: &str) -> Vec<u8>` function that serializes using the binary format above. The bc data comes from `parsed.iarrs[parsed.bc_idx]`.

For objects: iterate 0..parsed.obj_len, look up each index in the sparse `parsed.objs` vec (linear search by index is fine — small arrays). For missing slots, write tag 3 (Float) with value 0.0. For `ObjEntry::Float`, parse the string value: "1.0/0.0" → f64::INFINITY, "-1.0/0.0" → f64::NEG_INFINITY, otherwise parse as f64.

For blocks: iterate 0..parsed.block_len, look up each index. Missing slots → tag 0 (IArr) with value 0.

For bodies: iterate 0..parsed.body_len. Missing slots → 0u32. Each present body entry `(idx, iarrs_idx)` writes `iarrs_idx as u32`.

The main() function:
- Reads CBQN_PATH env var (hard error if missing)
- Finds gen/ dir using same `find_gen_dir` logic from current build.rs
- Parses all 4 components: runtime0, runtime1x (or runtime1 fallback), compiles, formatter
- Writes 4 .bin files to the `src/embedded/` directory (find it via CARGO_MANIFEST_DIR, or if that's not set, walk up from current dir to find `crates/rbqn/src/embedded/`)
- Prints what it did

**3. Update Cargo.toml:**
Add `gen-tools` feature (NOT in default features). Add `[[bin]]` entry for rbqn-gen with `required-features = ["gen-tools"]`. This ensures `cargo install rbqn` only installs the `rbqn` binary.

**4. Update embedded/mod.rs:**
Replace the `include!(concat!(env!("OUT_DIR"), "/embedded_bytecode.rs"))` with `include_bytes!` statics:
```rust
pub static RUNTIME0_BIN: &[u8] = include_bytes!("runtime0.bin");
pub static RUNTIME1_BIN: &[u8] = include_bytes!("runtime1x.bin");
pub static COMPILER_BIN: &[u8] = include_bytes!("compiler.bin");
pub static FORMATTER_BIN: &[u8] = include_bytes!("formatter.bin");
```

Add `OwnedBytecode` struct with the same fields as `EmbeddedBytecode` but owned (`Vec` instead of `&'static`):
```rust
pub struct OwnedBytecode {
    pub bc: Vec<i32>,
    pub iarrs: Vec<Vec<i32>>,
    pub objs: Vec<ObjectEntry>,
    pub blocks: Vec<BlockEntry>,
    pub bodies: Vec<usize>,
    pub source_tag: String,
}
```

Change `ObjectEntry::Str` to hold `Vec<u32>` instead of `&'static [u32]` (needed for owned decode).

Add `decode_bytecode(bytes: &[u8]) -> OwnedBytecode` function that reads the binary format using a cursor. Validate magic == b"RBQN", version == 1. Use `std::io::Cursor` and manual `read_exact` + `from_le_bytes` for each field.

Keep the old `EmbeddedBytecode` struct but mark it `#[allow(dead_code)]` — it will be removed once bootstrap.rs is updated. The old `include!` line must be DELETED.

**IMPORTANT**: The `ObjectEntry::Str` variant change from `&'static [u32]` to `Vec<u32>` will break the old generated code path. This is intentional — the old path is being replaced. If any code in bootstrap.rs pattern-matches on `ObjectEntry::Str(slice)`, update it to work with `&Vec<u32>` (which auto-derefs to `&[u32]`).
