       - r0.bqn → runtime0.bin (no runtime refs)
       - r1.bqn → runtime1x.bin (uses runtime_0 as RuntimePrev)

       - f.bqn  → formatter.bin (uses runtime as Runtime ref)

    6. Tags all output files with source_tag `"rbqn-self"`.

    7. Prints a success summary:
       ```
       rbqn-gen: --self: All 4 bins compiled and written to bins/
       rbqn-gen: --self: Commit bins/ to replace CBQN-compiled bytecode.
       ```

    8. On any compilation failure: print the error and exit 1 (do not write partial results).

    **Implementation structure:**
    - Add `self_mode = args.iter().any(|a| a == "--self")` at top of `main()`
    - If `self_mode`: call a new `self_compile_all(&embedded_dir)` function instead of the CBQN path
    - `self_compile_all` reuses `verify_self_compilation` logic but writes to `bins/` instead of `embedded/self-compiled/`, and exits 1 on failure rather than continuing

    **Finding `bins/` from `CARGO_MANIFEST_DIR`:**
    ```rust
    fn find_bins_dir() -> PathBuf {
        // CARGO_MANIFEST_DIR = {repo}/crates/rbqn
        // bins/ is at {repo}/bins/
        if let Ok(manifest) = env::var("CARGO_MANIFEST_DIR") {
            let p = PathBuf::from(manifest)
                .join("../..") // up to crates/, then up to repo root
                .join("bins");
            if let Ok(canonical) = p.canonicalize() {
                if canonical.is_dir() {
                    return canonical;
                }
            }
        }
        // Walk up from CWD
        let cwd = env::current_dir().unwrap_or_else(|_| PathBuf::from("."));
        let mut dir = cwd.as_path();
        loop {
            let candidate = dir.join("bins");
            if candidate.is_dir() {
                return candidate;
            }
            match dir.parent() {
                Some(p) => dir = p,
                None => break,
            }
        }
        // Fallback: create it
        let fallback = PathBuf::from("bins");
        fs::create_dir_all(&fallback).ok();
        fallback
    }
    ```
