  <files>crates/rbqn-prim/src/structural.rs, crates/rbqn-prim/src/arith_dyad.rs</files>
  <action>
fill.bqn has 28 failures. Fill elements are the default values used when padding arrays (e.g., `5↑1‿2‿3` pads with fill 0, `5↑"ab"` pads with fill ' '). The `BqnArr` struct already has a `fill: Option<B>` field.

Run fill.bqn first to get exact failure messages. Then fix these fill propagation gaps:

**Reshape (⥊) fill propagation:**
- When `⥊` creates a new array by cycling, preserve the fill from the source array.
- `fill(n⥊x) = fill(x)` — the fill of a reshaped array is the fill of the original.

**Transpose (⍉) fill propagation:**
- `fill(⍉x) = fill(x)` — transposing preserves fill.

**Shift (« and ») fill propagation:**
- `fill(»x) = fill(x)` — before-shift fills with fill element.
- `fill(«x) = fill(x)` — after-shift fills with fill element.
- Currently shifts might use 0 or space as fill; they should use `x.fill` if available.

**Group (⊔) fill propagation:**
- `fill(⊔x) = fill(x)` per element — each group inherits the fill from the source.

**Arithmetic fill propagation:**
- For pervasive operations on nested/boxed arrays, the fill of the result should be computed from the fills of the operands.
- `fill(x+y) = fill(x)+fill(y)` when fills are available.
- This is subtle: when both operands have fills, attempt the operation on the fills to get the result fill. If it fails (type mismatch), result has no fill.

**Take (↑) fill propagation:**
- `fill(n↑x) = fill(x)` — take preserves fill (and pads with it when n > ≠x).
- This may already work. Verify.

**Join (∾) fill propagation:**
- `fill(x∾y)` should be the common fill of x and y. If fills match, use it; if different, no fill.

For each structural operation in structural.rs that creates a new BqnArr, ensure `fill` is set:
```rust
let mut result = BqnArr::new_with_shape(shape, data);
result.fill = source_arr.fill; // propagate from source
```

Run fill.bqn after each batch of fixes to track progress. Prioritize the operations that fix the most tests.
