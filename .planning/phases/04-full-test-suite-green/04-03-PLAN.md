  <name>Task 1: Wire block inverse body dispatch in derive.rs</name>
  <files>crates/rbqn-vm/src/derive.rs, crates/rbqn-vm/src/block.rs</files>
  <action>
The compiler already parses inverse bodies and stores them in Block fields (inv_x_body for monadic 𝕊⁼, inv_w_body for dyadic 𝕊⁼𝕨). But inv_reg in derive.rs never checks these fields — it always falls through to the BQN runtime which says "Can't invert blocks".

**Step 1: Add InvBlock variant to DerivedKind**

In derive.rs, add a new enum variant:
```rust
InvBlock { inv_kind: u8 }, // 0=monadic(inv_x), 1=dyadic_w(inv_w)
```

**Step 2: Add InvBlock constructor**

```rust
pub fn m_inv_block(bl: Arc<Block>, sc: Arc<Scope>, inv_kind: u8) -> B {
    store_derived(Derived {
        kind: DerivedKind::InvBlock { inv_kind },
        f: B::SENTINEL, g: B::SENTINEL, h: B::SENTINEL,
        bl: Some(bl), sc: Some(sc),
    })
}
```

**Step 3: In inv_reg, check FunBlock inverse bodies**

Before falling through to the BQN runtime inverse registration, add:
```rust
if let DerivedKind::FunBlock = d.kind {
    if let Some(ref bl) = d.bl {
        if bl.inv_x_body.is_some() {
            return m_inv_block(bl.clone(), d.sc.clone().unwrap(), 0);
        }
    }
}
```

NOTE: You may need to add `exec_block_with_body` to vm.rs if it doesn't exist — it's like `exec_block_with_args` but using a specific body instead of bodies[0]. Check the existing API and adapt. <task type="auto">
  <name>Task 2: Implement missing native inverses for undo.bqn</name>
  <files>crates/rbqn-vm/src/derive.rs, crates/rbqn-vm/src/modifiers.rs</files>
  <action>
undo.bqn has 18 failures. After Task 1 (block header inverses), some may be fixed. For the remaining, implement native inverses:

**⌽⁼ (rotate inverse):**
- Monadic: `⌽⁼x = ⌽x` (reverse is self-inverse). This should already work via BQN runtime.
- Dyadic: `n⌽⁼x = (-n)⌽x`. Add to native_inverse_reg: for prim 31 (⌽), return a wrapper that negates the left arg and calls rotate. Or handle in the inv_reg dispatch: when the undo modifier calls inverse on a partially-applied `n⊸⌽`, the result should be `(-n)⊸⌽`.

**⍉⁼ (transpose inverse):**
- Monadic for rank ≤ 2: `⍉⁼ = ⍉` (self-inverse).
- Monadic for rank > 2: `⍉⁼x` reverses the axis order. The default monadic ⍉ moves last axis to first; ⍉⁼ moves first axis to last. Implement as: `⍉⁼x = (1+↕r-1)∾⟨0⟩ ⍉ x` where r = rank of x (i.e., dyadic reorder with inverted permutation).

**+`⁼ (scan inverse):**
- `+`⁼x` computes successive differences: result[0] = x[0], result[i] = x[i] - x[i-1] for i > 0.
- This is the inverse of prefix sums. Add to the scan modifier dispatch in modifiers.rs: when scan-inverse is requested for `+`, compute the differences.
- For scan inverse in general (not just `+`): `F`⁼` requires that `F` has an inverse; the scan-inverse applies `F⁼` between successive elements.

**/⁼ (replicate inverse):**
- `/⁼x` where x is an integer array: computes counts. If `/counts ≡ x`, then `/⁼x = counts`.
- Actually, BQN `/⁼` gives `(/x)⁼y` — the count for each value in x. It's the group-count: `≠¨⊔x`.
- This is complex. Check what CBQN does. It may be handled by the BQN runtime's inverse table rather than needing a native implementation.

**×˜⁼ (self-multiply inverse = square root):**
- `×˜⁼x = √x`. In undo dispatch, when `×˜` is being inverted, return `√`.
- Check if this is handled by the BQN runtime already (it should be, since ×˜ = square, and square inverse = sqrt).

Focus on ⌽⁼, ⍉⁼, and +`⁼ first — these are the most clearly needed. For /⁼ and ×˜⁼, test whether the BQN runtime already handles them correctly.

Run undo.bqn after each fix to track progress.
