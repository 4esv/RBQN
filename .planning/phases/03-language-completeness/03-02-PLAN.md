**•Import (SYS-08):**

Register: `"import" => m_sys_fn(70)` in `sys_name_to_b`.

Create an import cache:
```rust
static IMPORT_CACHE: std::sync::LazyLock<Mutex<HashMap<String, B>>> =
    std::sync::LazyLock::new(|| Mutex::new(HashMap::new()));
```

Implement in `dispatch_sys_c1`:
- 70 (•Import x):
  1. Convert x to path string
  2. Resolve against •path (the importing script's directory) if relative
  3. Canonicalize path
  4. Check IMPORT_CACHE — if already loaded, return cached value
  5. Insert a sentinel ("currently loading") to detect circular imports
  6. Read file contents via `std::fs::read_to_string`
  7. Compile: call the compiler (need access to the Runtime's compiler function — use the global SYS_RUNTIME to get the compiler, then call `compile_and_exec` or equivalent)
  8. Execute the compiled block
  9. Store result in IMPORT_CACHE, replacing sentinel
  10. Return result

For circular import detection: if cache contains SENTINEL (B::SENTINEL), throw "•Import: circular import detected".

NOTE: •Import needs access to the compiler and runtime to compile the imported file. The `SYS_RUNTIME` global already stores the compiler. Follow the pattern in `dispatch_sys_c1` case 30 (•BQN) which already does compilation — reuse that logic but with file contents instead of inline string, and set •path/•name for the imported file's context.
