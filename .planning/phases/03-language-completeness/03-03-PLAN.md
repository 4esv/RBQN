Fields (each a monadic sys_fn unless noted):

- `Cos` (sys 101): `x.o2f().cos()` → f64

- `Acos` (sys 104): `x.o2f().acos()` → f64
- `Atan` (sys 105): monadic: `x.o2f().atan()`, dyadic: `w.o2f().atan2(x.o2f())`
- `Log` (sys 106): monadic: `x.o2f().ln()`, dyadic: `x.o2f().log(w.o2f())` (log base w of x... check CBQN: `w •math.Log x` = log_w(x) = ln(x)/ln(w))
- `Cbrt` (sys 107): `x.o2f().cbrt()` → f64
- `Hypot` (sys 108): dyadic only: `w.o2f().hypot(x.o2f())`
- `Erf` (sys 109): Needs implementation. Use a polynomial approximation (Horner form) or the Abramowitz & Stegun approximation. Maximum ~1e-7 relative error is acceptable.
- `Comb` (sys 110): Binomial coefficient. Dyadic: `w •math.Comb x` = C(x, w) = x! / (w! × (x-w)!). Use iterative multiplication to avoid overflow.
- `Fact` (sys 111): Factorial. `•math.Fact n` = n!. Use iterative product. For non-integers, use gamma function: `(x+1).ln_gamma().0.exp()` or the `gamma` function from libm.
- `GCD` (sys 112): Dyadic: Euclidean algorithm on `w.o2f().round() as i64` and `x.o2f().round() as i64`.
- `LCM` (sys 113): Dyadic: `|w × x| / GCD(w, x)`.
- `PI` (sys 114): Special — this is a constant, not a function. Register as an immediate value `B::m_f64(std::f64::consts::PI)` in the namespace scope (not as a sys_fn).

Build the NS object with GIDs for each lowercased field name ("sin", "cos", "tan", etc.).
Add dispatch_sys_c1 arms for sys 100-113 (monadic versions).

**•rand namespace (SYS-18):**

Create `make_rand_namespace()`:
- Cache in `static RAND_NS: LazyLock<Mutex<Option<B>>>`
- Register: `"rand" => make_rand_namespace()` in `sys_name_to_b`
- Also register `"makerand" => m_sys_fn(120)` for •MakeRand (creates a seeded PRNG)

Use a simple PRNG. CBQN uses wyrand. For simplicity, use Rust's standard `std::collections::hash_map::RandomState` or implement wyrand:
```
fn wyrand(state: &mut u64) -> u64 {
    *state = state.wrapping_add(0xa0761d6478bd642f);
    let t = (*state as u128).wrapping_mul((*state ^ 0xe7037ed1a0b428db) as u128);
    ((t >> 64) ^ t) as u64
}
```

Store PRNG state in a `static LazyLock<Mutex<u64>>` seeded from `std::time::SystemTime`.

Fields:
- `Range` (sys 121): Monadic: `•rand.Range n` returns random integer in [0, n). Dyadic: `shape •rand.Range n` returns array of random integers.
- `Deal` (sys 122): `•rand.Deal n` returns a random permutation of ↕n. Use Fisher-Yates shuffle.
- `Subset` (sys 123): `k •rand.Subset n` returns k random distinct indices from ↕n.

**Time functions (SYS-17):**

Register in `sys_name_to_b`:
- `"unixtime" => m_sys_fn(140)` — current Unix epoch in seconds (f64)
- `"monotime" => m_sys_fn(141)` — monotonic clock in seconds (f64)
- `"delay"    => m_sys_fn(142)` — sleep for x seconds, return x

Implement in `dispatch_sys_c1`:
- 140 (•UnixTime): `std::time::SystemTime::now().duration_since(UNIX_EPOCH).unwrap().as_secs_f64()` → B::m_f64
- 141 (•MonoTime): Need a static Instant for relative timing. Use `static START: LazyLock<Instant> = LazyLock::new(Instant::now)`. Then `START.elapsed().as_secs_f64()` → B::m_f64.
- 142 (•Delay): `std::thread::sleep(Duration::from_secs_f64(x.o2f()))`. Return x.

**Shell execution (SYS-20):**

Register: `"sh" => m_sys_fn(145)` in `sys_name_to_b`.

Implement in `dispatch_sys_c1`:
- 145 (•SH x): x is a BQN string containing the command.
  1. Convert x to Rust string
  2. Execute via `std::process::Command::new("sh").arg("-c").arg(&cmd).output()`
  3. Return a 3-element BQN list: `⟨exit_code, stdout_string, stderr_string⟩`
     - exit_code: `output.status.code().unwrap_or(-1)` as f64
     - stdout: `String::from_utf8_lossy(&output.stdout)` → BQN char array
     - stderr: `String::from_utf8_lossy(&output.stderr)` → BQN char array
  4. Build the 3-element boxed array and return it

On Windows, use `Command::new("cmd").arg("/C")` instead, but for now target Unix (macOS/Linux).

Implement in `dispatch_sys_c2`:
- 145 (w •SH x): w is options namespace or array. For now, if w is provided, extract any options (stdin input, etc.) or just ignore and use the same behavior as monadic. CBQN's dyadic •SH takes `options •SH args` where args is `⟨cmd, arg1, arg2...⟩`. Implement: if x is a string, use it as command; if x is an array of strings, use first as command and rest as arguments.

**•_while_ modifier (SYS-21):**

Add to `native_md2_c1` dispatch:
```rust
MD2_WHILE => {
    // F _while_ G: apply F while G returns 1
    let mut acc = x;
    loop {
        let cond = c1(g, acc);
        if !cond.is_f64() || cond.o2f() != 1.0 { break; }
        acc = c1(f, acc);
    }
    acc
}
```

Add to `native_md2_c2` dispatch:
```rust
MD2_WHILE => {
    let mut acc = x;
    loop {
        let cond = c2(g, w, acc);
        if !cond.is_f64() || cond.o2f() != 1.0 { break; }
        acc = c2(f, w, acc);
    }
    acc
}
```

Register in `sys_name_to_b` in `derive.rs`:
```rust
"_while_" => m_native_md2(MD2_WHILE),
```

Verify the `m_native_md2` function exists and creates a B value with MD2_TAG. If it doesn't exist, create it following the pattern of `m_native_fn` and `m_native_md1`:
```rust
pub fn m_native_md2(idx: usize) -> B {
    let id = store_derived(Derived {
        kind: DerivedKind::NativeMd2 { prim_idx: idx },
        f: B::SENTINEL, g: B::SENTINEL, h: B::SENTINEL,
        bl: None, sc: None,
    });
    tagu64(id << 3, MD2_TAG)
}
```
