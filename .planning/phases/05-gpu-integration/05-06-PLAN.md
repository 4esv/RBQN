**CPU fallback implementations in `derive.rs`:**

`fn math_softmax_cpu(x: B) -> B`:
1. Extract x as a rank-1 numeric array
2. Find max value
3. Subtract max from all elements (numerical stability)
4. Compute exp of each element
5. Sum all exp values
6. Divide each exp value by sum
7. Return as F64 array

`fn math_matmul_cpu(w: B, x: B) -> B`:
1. Extract w as rank-2 array (M x K), x as rank-2 array (K x N)
2. Verify inner dimensions match: w.shape[1] == x.shape[0]
3. Naive triple-loop: `result[i][j] += w[i][k] * x[k][j]`
4. Return as F64 array with shape [M, N]

**Function pointer hooks (same pattern as arith/sort/fold):**

In `derive.rs`:
```rust
type GpuMatMulFn = fn(w: B, x: B) -> Option<B>;
type GpuSoftmaxFn = fn(x: B) -> Option<B>;
static GPU_MATMUL_HOOK: OnceLock<GpuMatMulFn> = OnceLock::new();
static GPU_SOFTMAX_HOOK: OnceLock<GpuSoftmaxFn> = OnceLock::new();

pub fn register_gpu_matmul(f: GpuMatMulFn) { let _ = GPU_MATMUL_HOOK.set(f); }
pub fn register_gpu_softmax(f: GpuSoftmaxFn) { let _ = GPU_SOFTMAX_HOOK.set(f); }
```

**In `gpu_runtime.rs`, add GPU dispatch implementations:**

`pub fn gpu_matmul(w: B, x: B) -> Option<B>`:
1. Check `get()` returns Some
2. Extract w and x as rank-2 BqnArr
3. Get dimensions: M = w.shape[0], K = w.shape[1], N = x.shape[1]
4. Verify K == x.shape[0]
5. Check total elements exceed threshold: `M*K + K*N >= 50_000`
6. Convert both arrays to f32 (matmul kernel uses f32). For F64 arrays, check `gpu_safe_integer` first or just convert (matmul is a floating-point operation, so f64→f32 precision loss is acceptable for ML use cases).
7. Upload as f32 GpuBuffers via `upload_f32`
8. Create output buffer: `GpuBuffer::storage(device, ElementKind::F32, M*N)`
9. Call `rbqn_gpu::kernels::matmul::matmul(device, queue, cache, &a_buf, &b_buf, &out_buf, M as u32, N as u32, K as u32)`
10. `device.poll(wgpu::Maintain::Wait)`
11. Download f32 result via `download_f32`
12. Convert back to f64: `result.iter().map(|&v| v as f64).collect()`
13. Create BqnArr with ArrData::F64, shape [M, N], fill Some(B::m_f64(0.0))
14. Log dispatch, wrap in catch_unwind

`pub fn gpu_softmax(x: B) -> Option<B>`:
1. Check `get()` returns Some
2. Extract x as rank-1 BqnArr
3. Check `x.ia() >= 256` (softmax kernel handles <=256 in single workgroup, larger via multi-pass)
4. Convert to f32 values
5. Upload as f32 GpuBuffer via `upload_f32`
6. Create output buffer: `GpuBuffer::storage(device, ElementKind::F32, n)`
7. Call `rbqn_gpu::kernels::softmax::softmax(device, queue, cache, &input_buf, &out_buf)`
8. `device.poll(wgpu::Maintain::Wait)`
9. Download f32 result, convert to f64
10. Create BqnArr with ArrData::F64, shape [n], fill Some(B::m_f64(0.0))
11. Log dispatch, wrap in catch_unwind

**In `main.rs`, register hooks after gpu_runtime::init:**
