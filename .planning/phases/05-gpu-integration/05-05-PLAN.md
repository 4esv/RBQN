**Create `crates/rbqn/benches/gpu_bench.rs`:**

The benchmark file should:

1. **Setup:** Initialize `GpuContext` via `pollster::block_on` in a shared setup function. Skip benchmark gracefully if no GPU available (print warning, return).

2. **Benchmark groups (each with 50K, 100K, 500K sizes):**

   a. **`reduce_add`** — GPU reduce vs CPU sum:
   ```rust
   fn bench_reduce_add(c: &mut Criterion) {
       let ctx = setup_gpu();
       let mut group = c.benchmark_group("reduce_add");
       for size in [50_000, 100_000, 500_000] {
           let data: Vec<i32> = (0..size).map(|i| (i % 100) as i32).collect();
           let buf = upload_i32(&ctx.device, &ctx.queue, &data);

           group.bench_with_input(
               BenchmarkId::new("gpu", size),
               &size,
               |b, _| {
                   let mut cache = PipelineCache::new(ctx.device.clone());
                   b.iter(|| {
                       let result = reduce(&ctx.device, &ctx.queue, &mut cache, "add", &buf);
                       ctx.device.poll(wgpu::Maintain::Wait);
                       result
                   })
               },
           );

           group.bench_with_input(
               BenchmarkId::new("cpu", size),
               &size,
               |b, _| b.iter(|| data.iter().copied().sum::<i32>()),
           );
       }
       group.finish();
   }
   ```

   b. **`arith_add`** — GPU elementwise add vs CPU:
   ```rust
   fn bench_arith_add(c: &mut Criterion) {
       // Similar pattern: upload two arrays, benchmark arith_binary("add", a, b, out)
       // vs CPU: a.iter().zip(b.iter()).map(|(a,b)| a+b).collect()
   }
   ```

   c. **`scan_add`** — GPU prefix sum vs CPU:
   ```rust
   fn bench_scan_add(c: &mut Criterion) {
       // Benchmark inclusive_scan vs CPU prefix sum loop
   }
   ```

3. **Criterion group and main:**
   ```rust
   criterion_group!(benches, bench_reduce_add, bench_arith_add, bench_scan_add);
   criterion_main!(benches);
   ```

4. Each GPU benchmark should call `ctx.device.poll(wgpu::Maintain::Wait)` inside the measured closure to ensure GPU work completes before the next iteration.

5. CPU benchmarks should use simple iterators to represent the "baseline" — not the full BQN pervasive_dyad path, just raw Rust iteration, since we want to measure kernel performance not BQN overhead.
