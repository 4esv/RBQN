**What syntax.bqn tests (156 value tests + 88 error tests):**

Major categories:
1. **Trains** (37 tests): `(⌈-)4+÷2`, `√5(+×-)4`, `×˜-3`, `3-˜4`, `4-˜○÷2`
   - Fork: `(f g h) x = (f x) g (h x)`, `x (f g h) y = (x f y) g (x h y)`
   - Atop: `(g h) x = g(h x)`, `x (g h) y = g(x h y)`
   - Self/swap via `˜`: `×˜3 = 3×3 = 9`, `3-˜4 = 4-3 = 1`
   - Fix in derive.rs (Fork, Atop dispatch) if broken

2. **Repeat/Power** (6 tests): `3(2×+⍟(1+1))2`, `2+⍟3-1`
   - `⍟` applies a function N times
   - Fix in modifiers.rs (repeat_c1/repeat_c2) if broken

3. **Nothing (·)** (8 tests): `(1+·)-4`, `·⋄1`, `(·-⊑)¯2‿3`
   - Nothing as a placeholder that gets filled by context
   - Fix in vm.rs (NOTM, optional dispatch) if broken

4. **Define/Modify** (20 tests): `F←-⋄F 3`, `n←2⋄n↩3`, `x←4⋄x-↩1`, `a‿b←2‿0⋄a‿b+↩2`
   - Variable definition and redefinition
   - Modify-assign with destructuring
   - Fix in vm.rs (SETN/SETU/SETM/SETC, LSTM) if broken

5. **Lists** (12 tests): `⟨0,1⟩`, `2‿+‿-‿1`, `f←0⊑⟨×,-⟩`
   - Array and list construction
   - Fix in vm.rs (LSTO) if broken

6. **High-rank arrays** (8 tests): `[,0,1,2]`, `{[𝕩]≡≍𝕩}"ab"`
   - ARMO opcode for array merge
   - Fix in vm.rs (ARMO) if broken

7. **Blocks with headers** (15 tests): `2{𝕩÷𝕨}6`, recursion via `𝕣`
   - Block headers with explicit argument names
   - `{(0⊸<)◶⟨𝕗,(𝕗×𝕩)_𝕣⟩ 𝕩-1}` — recursive modifier via 𝕣 self-reference
   - Fix in vm.rs (SETH1/SETH2) and compiler.rs if broken

8. **Error tests** (88 cases): `()`, `+∘∘-`, `(+)∘`, `(`, `⟩⟨`, `{{`
   - These must throw errors, caught by `⎊`
   - If catch works correctly and the compiler throws on invalid syntax, these should pass

**Strategy:** Work through failures category by category. Start with trains and define/modify (most fundamental), then move to blocks with headers (most complex). Use `CBQN/BQN` as ground truth for every ambiguous case.
