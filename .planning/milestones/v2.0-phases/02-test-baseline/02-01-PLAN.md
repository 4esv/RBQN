  <files>crates/rbqn-vm/src/derive.rs, crates/rbqn-vm/src/namespace.rs</files>
  <action>
Implement the `•file` namespace object in derive.rs so that `•file.Lines` and `•file.List` work. Three sub-steps:

**1a. Add `•file.Lines` implementation (new function `file_lines_c1`):**
- Takes a B char array (the path string), converts via `b_to_string`
- Calls `std::fs::read_to_string(&path)` — use CWD-relative paths (do NOT add any prefix)
- On error, call `rbqn_core::error::throw(format!("•file.Lines: cannot read {path}: {e}"))`
- Split on lines using `content.lines()` (Rust's `str::lines()` correctly handles trailing newlines)
- Map each line to a BQN char array: `chars.map(|c| c as u32).collect()` -> `BqnArr::new_vec_c32` -> `tag_arr`
- Collect into `Vec<B>` and return via `crate::vm::b_vec_to_arr(lines)`
- Register as a new sys_idx (e.g., 50)

**1b. Add `•file.List` implementation (new function `file_list_c1`):**
- Takes a B char array (the directory path), converts via `b_to_string`
- Calls `std::fs::read_dir(&path)`, on error throw with "•file.List: cannot list {path}: {e}"
- Filter entries: `.filter_map(|e| e.ok()).filter_map(|e| e.file_name().into_string().ok())`
- **Sort alphabetically** (read_dir returns arbitrary order)
- Map each name to BQN char array, collect via `b_vec_to_arr`
- Register as a new sys_idx (e.g., 51)

**1c. Build the `•file` namespace object:**
- In `sys_name_to_b`, add `"file" => make_file_namespace()`
- `make_file_namespace()` builds a synthetic NS object using the existing `store_ns(NS { desc, sc })` infrastructure
- The NS must have two exported fields: `"lines"` (gid for "lines") and `"list"` (gid for "list")
- Use `str2gid("lines")` and `str2gid("list")` from namespace.rs to get GIDs
- Create an `NSDesc` with `var_am: 2` and `exp_gids: vec![lines_gid, list_gid]`
- Create a `Scope` whose vars hold the two sys_fn B values: `[m_sys_fn(50), m_sys_fn(51)]`
- The Scope needs a Body — create a minimal Body with `bc_offset: 0, var_am: 2, max_stack: 0, max_psc: 0, ns_desc: None`
- Use a lazy static (`LazyLock<Mutex<Option<B>>>`) to cache the namespace B value so it's only built once
- The FLDO opcode in vm.rs already handles NS field lookup via `get_ns` + `desc.exp_gids` — verify this path works

**Important:** The Scope constructor may need adjustment. Look at how existing NS objects are created in the codebase (search for `store_ns` calls). If Scope::new requires a parent scope or specific initialization, match the existing pattern. If no existing NS construction exists in Rust code (only from VM execution), you may need to create a minimal constructor. The key requirement is that `get_ns(ns_b)` returns an NS whose `desc.exp_gids` maps field names to scope variable indices, and `sc.vars[idx]` returns the correct function B value.

```rust
//! Integration tests for running the official BQN test harness via RBQN.
//! Requires CBQN_PATH set and BQN test repo at /Users/axel/Code/forks/BQN.

use std::process::Command;

fn rbqn_harness(args: &[&str]) -> std::process::Output {
    Command::new("cargo")
        .args(["run", "-p", "rbqn", "--quiet", "--"])
        .args(args)
        .current_dir("/Users/axel/Code/forks/BQN/test")
        .env("CBQN_PATH", "/Users/axel/Code/forks/CBQN")
        .output()
        .expect("failed to execute rbqn")
}

#[test]
#[ignore] // Run manually: cargo test -p rbqn --test harness -- --ignored
fn harness_runs_without_crash() {
    let output = rbqn_harness(&["this.bqn", "simple", "literal", "syntax", "bytecode"]);
    let stdout = String::from_utf8_lossy(&output.stdout);
    let stderr = String::from_utf8_lossy(&output.stderr);
    eprintln!("STDOUT:\n{stdout}");
    eprintln!("STDERR:\n{stderr}");
    // The harness should complete (exit, not crash)
    // It may exit non-zero if tests fail, but it should not panic
    assert!(!stderr.contains("panicked"), "Harness panicked: {stderr}");
}
```
