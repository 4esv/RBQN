</objective>

  <name>Task 1: Implement system value resolver and critical system functions</name>
  <files>

  <action>
    The compiler calls sys_idx 100 with an array of system value name strings. Currently this
    returns the input unchanged (placeholder). This must be a proper resolver that maps names
    to callable B values.

    Step 1: Define system value name→index mapping. CBQN uses these names (lowercase):
    - "type"→0, "decompose"→1, "glyph"→4, "primind"→5, "fill"→7
    - "bqn"→30, "rebqn"→31, "out"→32, "show"→33, "fmt"→34, "repr"→35
    - "exit"→36, "args"→37, "path"→38, "name"→39, "wdpath"→40, "state"→41
    Use new sys_idx numbers (30+) that don't conflict with existing bootstrap indices.

    Step 2: Update dispatch_sys_c1 for sys_idx 100: when called with an array of name strings,
    return an array of the corresponding system value B values. For each name:
    - Look up in the name→index map
    - Return m_sys_fn(idx) for known names
    - Return B::SENTINEL for unknown names (signals to BQN runtime that the value is unavailable)

    Step 3: Implement each system function in dispatch_sys_c1/c2:

    **•Out (sys_idx 32):** c1 prints x (must be string) to stdout with newline, returns x.
    Convert character array to String, println!, return x.

    **•Show (sys_idx 33):** c1 formats x using the bootstrap formatter (if available) or
    format_b fallback, prints to stderr with newline, returns x.

    **•BQN (sys_idx 30):** c1 takes a BQN source string, compiles and executes it using the
    same exec_string mechanism. This requires access to the Runtime struct. Options:
    - Store a clone of rt.compiler and rt.runtime in a global (simplest)
    - Use a thread-local
    Choose the simplest approach. Store compiler+runtime+formatter in a global after bootstrap.
    When dispatch_sys_c1(30, x) is called, retrieve the global, call exec_string equivalent.

    **•Exit (sys_idx 36):** c1 takes a number, calls std::process::exit(n as i32).

    **•Fmt (sys_idx 34):** c1 formats x using the bootstrap formatter function (rt.formatter.0).
    If formatter unavailable, use format_b fallback.

    **•Repr (sys_idx 35):** c1 formats x using the repr function (rt.formatter.1).
    If unavailable, fall back to a basic repr.

    Step 4: Implement environment values. These are not functions but values:
    - •args (sys_idx 37): Returns a string list of command-line arguments after the file.
      Store via a global set in main.rs before REPL/eval.
    - •path (sys_idx 38): Returns the path of the currently executing file, or "" for -e/-p.
    - •name (sys_idx 39): Returns the name of the current source file.
    - •wdpath (sys_idx 40): Returns the working directory path.
    - •state (sys_idx 41): Returns a namespace-like state object (can be a placeholder).

    For environment values, return the value directly when the system value is looked up
    (in sysv_lookup or in the name resolver).

    Step 5: Update sysv_lookup in vm.rs to include all new system indices.

    Step 6: Wire •BQN into the system value resolver so that when the compiler encounters
    `•BQN` in user code, it resolves to sys_idx 30.
  </action>
